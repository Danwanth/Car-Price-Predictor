# Car Price Predictor

A Machine Learning based web application that predicts the selling price of a used car using various car features such as fuel type, transmission, engine capacity, mileage, kilometers driven, and more.

Built using:
- Python
- Scikit-learn
- Random Forest Regressor
- Streamlit

---

# Features

- Predicts used car prices instantly
- Interactive Streamlit web interface
- Uses Random Forest Regression model
- Handles categorical data using One-Hot Encoding
- Includes feature engineering (`car_age`)
- Log-transformed target handling for better prediction accuracy

---

# Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
